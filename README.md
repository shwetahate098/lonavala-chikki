# Lonavala Chikki & Crunch

React + Vite shop website. Customers pick flavours and send the order on WhatsApp.

## Run it
1. Install Node.js (version 18 or newer) from nodejs.org
2. Open a terminal in this folder
3. `npm install`
4. `npm run dev` and open the link it shows

## Change your details
- `src/config.js`: WhatsApp number, shop name, address
- `src/menu.js`: flavours, prices and colours

## Put it online
`npm run build` makes a `dist` folder. Upload that folder to Netlify, Vercel or any hosting.
